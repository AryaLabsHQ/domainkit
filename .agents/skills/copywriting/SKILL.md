# Copywriting

Write clear, specific copy that matches what the released packages do today.

## First move

Read `.agents/marketing/truth.md`, `positioning.md`, `voice.md`, and the rows in `proof-registry.md`
the page will lean on. Truth governs claims; positioning governs audience, story, and vocabulary;
voice governs style. Truth wins on conflict. The canon is not evidence: every objective claim needs
a proof-registry row.

## Workflow

1. Name the reader (evaluator or end customer), the page's search term, and its one primary action.
2. **Structure.** Outline sections mapped to story beats (positioning) and proof rows. One section
   advances one argument. Show the outline as an Artifact before writing prose.
3. **Text-only prototype.** Headings, copy, code snippet references, proof notes, and CTAs for the
   whole page in one Artifact, no design. Sonnet subagents draft; the coordinator reviews. Wait for
   approval.
4. **Metadata.** Title 60 columns or fewer; description 110 to 160 characters; H1 in customer words
   with the search term; open with the quotable definition sentence (positioning).
5. Check each claim against the registry. Cut adjectives that a number or a record could replace.
6. When code is involved, change the smallest surface and verify the rendered text. Code samples are
   slices of `examples/` files, never hand-written.

## Comparison pages

Frame by mechanism, control, safety semantics, and layer (positioning). Credit the rival first,
link each claim to the vendor's own page, end with a dated evidence footer, and stop for owner
sign-off. Never "successor", "Domain Connect is dead", or unsourced prices.

## Handoff to design

Pass the approved copy, proof rows, target surface, and accessibility needs. This skill does not
prescribe layout, motion, or visual implementation.
