## Verdict

Manual instructions work when a few people follow them carefully. They break at volume, because
each customer has to copy exact values into an interface you don't control. The fix is to take the
copying away, so the answer is a different flow and not a better page.

These are good docs for a hard problem. The failures below come from the task, not from the writing.

## Where they break

The same problems show up across all five.

1. **Field names differ by registrar.** One wants @ for the host and another wants the bare domain
   (Webflow).
2. **Registrars change what you type.** Some add the domain name to the host, or need a trailing dot
   (Webflow, Resend).
3. **Values are long and exact.** DKIM values are long keys.
4. **Quoting rules vary.** A TXT value must be in quotes at one registrar and must not be at
   another (Postmark, DigitalOcean guide).
5. **Some records can't exist together.** A CNAME can't share a name with other records, and some
   registrars can't put one at the root (Ghost).
6. **Then the customer waits.** Vendors say it can take up to 48 hours, and the customer has no way
   to tell a wait from a mistake (Webflow, Postmark).

Several vendors ship a variant for each registrar to cope. That is a lot of maintenance for a page
the customer reads once.

## When manual is fine

If you have a handful of customers, a clear page and a Verify button is the right amount of
engineering. If your customers are technical and use one registrar, it may be enough for a long
time.

## What DomainKit changes

For customers on Cloudflare or Vercel, DomainKit removes the copying. The customer connects their
account, sees the exact records in a table, and presses one button. DomainKit writes them and keeps
checking public DNS until they resolve.

It doesn't change anything for customers on other providers. They still need instructions.

## Keep a manual path

Keep your instruction page as the fallback. Your requirements are plain values, so the same
declaration can drive both the automatic flow and a table for manual entry. When a plan exists,
`Plan.renderInstructions` renders it as copyable lines.

## FAQ

<Accordion>
  <AccordionItem title="Are copy-paste instructions bad?">
    No. They work, and they're the only option for a provider you can't write to. They cost more as
    your customer count grows.
  </AccordionItem>
  <AccordionItem title="Does DomainKit remove the need for instructions?">
    Only for Cloudflare and Vercel. Keep instructions for everything else.
  </AccordionItem>
  <AccordionItem title="Won't a customer still be nervous about connecting an account?">
    Possibly. DomainKit shows every record before anything changes and writes only what the customer
    approves, which is the answer to that worry.
  </AccordionItem>
</Accordion>
