## Props

| Prop       | Type                  | Required | Means                                     |
| ---------- | --------------------- | -------- | ----------------------------------------- |
| `provider` | `Provider.Descriptor` | yes      | The provider as the snapshot describes it |

`marks` is keyed by provider id and takes a node or a function of the descriptor. Without an entry,
the mark is the provider's own initial drawn with the theme's tokens, so a provider list renders
before any artwork exists.

## Accessibility

The mark carries `role="img"` and the provider's name as its label, so replacing the artwork does
not remove the name from the accessibility tree.
