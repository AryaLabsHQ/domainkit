## Props

| Prop        | Type                       | Required | Means                           |
| ----------- | -------------------------- | -------- | ------------------------------- |
| `record`    | `DnsRecord.Model`          | yes      | The requirement to show         |
| `readiness` | `Verify.Readiness \| null` | no       | Adds the status for this record |

`Records.identity(record)` gives the card a stable key, and the card's own leaf parts
(`CardHeader`, `CardTitle`, `CardContent`) are exported for a host that wants a different shell.

## When to use it

Use the card where a table would not fit: a narrow settings column, a mobile layout, or a screen
that shows one record at a time. Use `Records.Table` when the customer needs to compare several.
