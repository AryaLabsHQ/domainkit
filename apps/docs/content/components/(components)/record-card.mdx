title: Record Card
description: Show one DNS record with copy controls, priority, and provider or public-DNS evidence while keeping the result easy to scan.
---

`Records.Card` is an alternative to the records table for setup steps, narrow layouts, and
record-by-record progress.

<ReactExample story="card" />

## Installation

```package-install
@domainkit/react domainkit effect @effect/atom-react react react-dom
```

The [Registry](/components/registry) also provides presentation parts when you want to own the card
markup. Use the package component when you need DomainKit's record and observation types.

## Usage

Pass one `DnsRecord` and any evidence for its `id`:

```tsx
<Records.Card
  record={record}
  evidence={observation.publicDns.filter((item) => item.recordId === record.id)}
/>
```

The card renders the record type, name, value, optional priority, copy controls, and matching evidence.
It does not turn several observations into one product status.

## Composition

Use `CardHeader`, `CardTitle`, `CardContent`, `CopyValue`, `Priority`, and `Status` when you need a
different structure but want the same parts and state-aware styling.

## Accessibility

Keep the record type visible as the card title. Copy controls should announce both the action and
the value. Do not communicate observation failures or pending propagation through color alone.
