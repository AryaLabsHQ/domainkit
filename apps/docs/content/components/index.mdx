Every interactive component here runs over a transport your app supplies, so credentials, routes,
storage, tenants, consent, and audit policy stay in your app. The previews on these pages run the
real lifecycle against an in-memory server, so clicking through them behaves the way a real
integration does.

## Registry

The registry ships plain React display components you copy into your project with the shadcn CLI.
They import no DomainKit runtime and render only the props you pass them.
