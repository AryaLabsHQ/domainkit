Everything on these pages is a file you copy into your project. `@domainkit/react` supplies the
behaviour, the state, the copy, and the accessibility; the registry supplies the markup, written
against your own kit.

The previews run the real lifecycle against an in-memory server, so clicking through them behaves
the way a real integration does.
