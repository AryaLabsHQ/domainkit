Add custom-domain setup with complete flows or smaller parts from `@domainkit/react`. Every
interactive component uses a transport supplied by your app. Your app keeps the credentials, routes,
storage, users, tenants, consent, and audit policy.

## Registry

Copy standalone display components into your application through the DomainKit Shadcn registry. Each
item has its own live preview, source view, install command, usage example, and API
reference.
