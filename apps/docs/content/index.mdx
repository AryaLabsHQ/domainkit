DomainKit helps you add custom domains to a SaaS product. Your app says which DNS records it needs.
DomainKit connects a supported provider, builds a plan you can review, applies the approved changes,
checks DNS, and records what happened.

Your app keeps control of users, credentials, storage, routes, and product rules. Use the Effect API
at the core, the Promise API when your app uses async/await, and `@domainkit/react` for browser-safe
flows over your server.

```package-install
domainkit
```

## Product boundary

| DomainKit owns                       | Your application owns                      |
| ------------------------------------ | ------------------------------------------ |
| DNS requirements and plans           | Your product's DNS requirements            |
| Approval for an exact plan           | Users, tenants, consent, and audit policy  |
| Cloudflare and Vercel integrations   | Credential encryption and storage          |
| Provider and public DNS checks       | Authenticated routes and product readiness |
| Cleanup plans tied to apply receipts | When and how users may remove records      |
| React lifecycle contracts            | Branding, layout, messages, and telemetry  |

## Safety model

- **Review before a write.** A plan lists creates, exact no-ops, and conflicts before anything changes.
- **Approve the exact plan.** Apply accepts the reviewed plan and approval for its digest.
- **Stop on conflicts.** DomainKit never silently overwrites incompatible DNS state.
- **Keep control in your app.** Your application owns credentials, consent, routes, storage, and audit history.
- **One implementation.** The Effect API is canonical; the Promise API uses it.

## Entry points

| Package             | Use it for                                                     |
| ------------------- | -------------------------------------------------------------- |
| `domainkit`         | Effect services, schemas, plans, providers, and typed failures |
| `domainkit/promise` | Promise API for apps that use async/await                      |
| `domainkit/server`  | Provider connection routes and an async Web handler            |
| `domainkit/testing` | In-memory services and provider tests                          |
| `@domainkit/react`  | React flows and DNS record UI over your server                 |
