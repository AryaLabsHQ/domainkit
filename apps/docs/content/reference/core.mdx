The package root is one module per concept. A service module exposes `Service` (the tag) and
`Interface` (its shape); a value module exposes `Model` (the schema).

```ts
import { DnsRecord, DomainKit, Provision, Verify } from "domainkit";
```

Every namespace below is also its own subpath, for a package that emits declarations or wants a
narrow import: see [entry points](/docs/reference/entry-points#one-subpath-per-namespace).

## Lifecycle services

Each one is a `Service` tag, an `Interface`, a `layer`, and free accessors that read the service
from context (`Provision.plan(...)`). `Policy` values are `Context.Reference`s with defaults.

| Namespace   | Owns                                                                                               |
| ----------- | -------------------------------------------------------------------------------------------------- |
| `Connect`   | `inspect`, `discover`, `start`, `complete`, `attach`, `detach`, `disconnect`, `refresh`, `session` |
| `Provision` | `plan`, `approve`, `reject`, `apply`, `get`, `latest` over durable attempts                        |
| `Cleanup`   | The same verbs over a plan built from an apply receipt                                             |
| `Verify`    | `observe`, `attachEvidence`, `latest`, and the evidence classes they produce                       |

## Host seams

| Namespace   | Owns                                                                             |
| ----------- | -------------------------------------------------------------------------------- |
| `Principal` | `{ ownerId, actorId }` per request; every Storage query is scoped by it          |
| `Storage`   | Every durable row, the row schemas, `layerMemory`, and `layerFromAsync`          |
| `Custody`   | Sealing credentials: `layer`, `layerConfig`, `layerFromAsync`, and `generateKey` |

## Providers

| Namespace    | Owns                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------- |
| `Provider`   | `Definition`, `make`, `tokenAuth`, `Session`, `Dns`, `Target`, `Resolution`, `fromAsync` |
| `Providers`  | The registry of enabled definitions, built by `DomainKit.layer`                          |
| `Cloudflare` | `provider`, `AccountContext`, `TokenFields`, and the OAuth server metadata               |
| `Vercel`     | `provider`, `TeamContext`, and `TokenFields`                                             |

## Values

| Namespace    | Owns                                                                                      |
| ------------ | ----------------------------------------------------------------------------------------- |
| `DomainName` | A normalized, IDN-aware hostname, its zone `candidates`, and `isWithin`                   |
| `DnsRecord`  | Record constructors, `Model`, `Observed`, `Opaque`, `data`, `equals`, `sameSet`           |
| `Plan`       | `Model`, the four operations, `writes`, `conflicts`, `isApplicable`, `renderInstructions` |
| `Approval`   | Consent bound to one plan digest and an explicit operation set                            |
| `Receipt`    | What an apply actually wrote: `Applied`, `Skipped`, `Failed`, `applied`, `isComplete`     |

## Everything else

| Namespace   | Owns                                                                             |
| ----------- | -------------------------------------------------------------------------------- |
| `DomainKit` | `layer`, `layerMemory`, `Error`, `ErrorCategory`, and `isError`                  |
| `Reason`    | The sixteen failure reasons and their union, `Reason.Model`                      |
| `Resolver`  | The public DNS pool: `layer` (Cloudflare and Google DoH), `layerWith`, `Outcome` |
| `VERSION`   | The installed package version, read from the package manifest                    |

## Composing the layer

`DomainKit.layer({ providers, resolver? })` provides every lifecycle service and requires `Storage`
and `Custody` beneath it. `DomainKit.layerMemory` adds the in-memory pair and a throwaway custody
key for tests and playgrounds.

## Failures

Every operation fails with `DomainKit.Error`. It carries one `Reason`, and `category`,
`isRetryable`, and `httpStatus` derive from it.

| Property      | Values                                                        |
| ------------- | ------------------------------------------------------------- |
| `reason`      | One member of `Reason.Model`                                  |
| `category`    | `request`, `auth`, `plan`, `provider`, `storage`, `internal`  |
| `isRetryable` | `true` for `Busy`, `ProviderUnavailable`, and `StorageFailed` |
| `httpStatus`  | The status `domainkit/server` answers with                    |

[Failure reasons](/docs/core/errors) lists every reason with its status and the next step.
