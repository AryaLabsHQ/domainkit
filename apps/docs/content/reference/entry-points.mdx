DomainKit publishes one core package with four entry points, an optional PostgreSQL persistence
package, and a React package. These names are the public contract; internal source paths are not.

## Install

```package-install
domainkit effect@rc
```

Add the React package when the product needs ready-made flows or UI parts:

```package-install
@domainkit/react react react-dom
```

Add the persistence package when the host runs Effect on PostgreSQL:

```package-install
@domainkit/capsuledb capsuledb @effect/sql-pg
```

## Entry points

| Import                        | Carries                                                                  |
| ----------------------------- | ------------------------------------------------------------------------ |
| `domainkit`                   | Lifecycle services, host seams, providers, values, and `DomainKit.Error` |
| `domainkit/server`            | `Server.group`, its layers, `Server.Identity`, and the wire schemas      |
| `domainkit/client`            | `Transport.fromFetch` and the Promise adapters                           |
| `domainkit/testing`           | Fakes, the recording transport, and the conformance runners              |
| `@domainkit/react`            | React flows, controllers, parts, messages, and themes                    |
| `@domainkit/react/styles.css` | The optional default stylesheet                                          |
| `@domainkit/capsuledb`        | `Storage` on PostgreSQL as one CapsuleDB capsule                         |

`domainkit/client` runs in the browser and holds no credential. `domainkit/server` and
`@domainkit/capsuledb` run on the server and never reach browser code.

## Where each one runs

```text
browser                        server
-------                        ------
@domainkit/react               domainkit/server   -> domainkit
  -> domainkit/client  --HTTP-->                     -> @domainkit/capsuledb
                                                     -> provider APIs
```

## Runtime requirements

- `domainkit` needs Node.js 24.10 or newer and Effect 4 as a peer dependency.
- `@domainkit/react` needs React 19 and React DOM 19 beside those.
- `@domainkit/capsuledb` needs `capsuledb` and a host-owned `SqlClient`.

Install `domainkit` and `@domainkit/react` at the same release version. The React package decodes
the core package's schemas, so mixed versions can disagree about a shape.
