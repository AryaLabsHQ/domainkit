DomainKit publishes core imports and a React package. Use the public names below; internal source
paths are not part of the API.

## Install

```package-install
domainkit effect@rc
```

Add the React package when your product needs ready-made flows or UI parts:

```package-install
@domainkit/react @effect/atom-react@rc react react-dom
```

## Entry points

| Import                        | Purpose                                                       |
| ----------------------------- | ------------------------------------------------------------- |
| `domainkit`                   | Canonical Effect services, schemas, plans, providers, and DNS |
| `domainkit/promise`           | Promise API for apps that do not use Effect                   |
| `domainkit/server`            | Provider connection routes and an async Web handler           |
| `domainkit/testing`           | In-memory services and provider tests                         |
| `@domainkit/react`            | React flows, models, UI parts, messages, and themes           |
| `@domainkit/react/styles.css` | Optional default styles for the React package                 |

The Promise and Web handler boundaries adapt the same Effect-native lifecycle. They do not define
second lifecycles or wire protocols. Prefer Layers inside Effect applications and adapt only where
the host framework requires a standard Web handler.

## Runtime requirements

- `domainkit` requires Node.js 24.10 or newer and Effect 4.
- `@domainkit/react` requires React 19, React DOM 19, Effect 4, and Effect Atom React 4.
- Provider credentials, OAuth state, connections, plans, and receipts stay on the server.

## Version alignment

Install `domainkit` and `@domainkit/react` at the same release version. The React transport uses
models from the core package, so mixed versions can disagree about schemas and results.

Continue with the [Core API](/docs/reference/core), [Promise API](/docs/reference/promise),
[Server API](/docs/reference/server), [Testing API](/docs/reference/testing), or
[React components](/components).
