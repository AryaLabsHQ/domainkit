## Fakes

| Value                 | Gives                                                                           |
| --------------------- | ------------------------------------------------------------------------------- |
| `Testing.provider`    | A provider definition with a token method, optional OAuth, over in-memory zones |
| `Testing.resolver`    | A `Resolver` answering from those zones, or from a table you pass               |
| `Testing.storage`     | `Storage.layerMemory`, re-exported here for discoverability                     |
| `Testing.principal`   | A fixed `{ ownerId, actorId }` for tests that do not care which tenant          |
| `Testing.transport`   | The whole lifecycle behind a `Transport.Interface`, recording every call        |
| `Testing.fakeRecords` | What the fake providers currently hold for a name                               |

### Options

| Option               | Effect                                                                                           |
| -------------------- | ------------------------------------------------------------------------------------------------ |
| `id`                 | The provider id. Default `fake`                                                                  |
| `zones`              | Zones the fake credential reaches. Default `example.com`                                         |
| `records`            | Pre-existing records, to produce `Noop` and `Conflict` operations                                |
| `oauth`              | Offer OAuth beside the token method; the fake redirects to `callbackUrl` immediately             |
| `failWrite`          | Fail the write at this zero-based index, to exercise a partial receipt                           |
| `nameservers`        | Nameservers per zone, which `Testing.resolver` answers NS queries from                           |
| `nameserverSuffixes` | Suffixes the fake declares as `Definition.nameservers`, so `Connect.discover` names it as a host |

:::caution
`Testing.provider` registers its zones in one table shared by the whole process, and
`Testing.resolver()` answers from that table. Give each test its own zone, or a record another test
applied will answer a public DNS query here.
:::

## The recording transport

<Snippet file="examples/testing/fakes.ts" region="transport" title="A transport for UI tests" />

`Testing.transport` mounts `domainkit/server` over memory storage and a fake provider, then wraps
`Transport.fromFetch` around that handler. `calls` holds `{ method, input }` for every call, oldest
first, where `method` reads `connection.inspect`, `provisioning.approve`, and so on. There is
nothing to dispose.

## Conformance

| Runner                         | Checks                                                                                          |
| ------------------------------ | ----------------------------------------------------------------------------------------------- |
| `Testing.conformance.storage`  | Tenant isolation, apply leases, exactly-once continuations, revocation recovery, locks          |
| `Testing.conformance.provider` | Create and read back, exact no-op, conflict, stale plan, partial apply, cleanup, rejected token |
