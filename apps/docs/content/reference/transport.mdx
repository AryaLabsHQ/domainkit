## Capability groups

Every group on `Transport.Interface` is optional, so a host that mounts part of the route group gets
a transport that typechecks and a UI that renders only what the server can serve.

| Group          | Methods                                                                   |
| -------------- | ------------------------------------------------------------------------- |
| `connection`   | `inspect`, `discover`, `zones`, `start`, `attach`, `detach`, `disconnect` |
| `provisioning` | `plan`, `approve`, `reject`, `apply`, `attempt`, `receipt`                |
| `verification` | `observe`                                                                 |
| `cleanup`      | `plan`, `approve`, `reject`, `apply`                                      |

`connection.zones(filter?)` answers with every zone this owner's connections reach, how each
connection stands, and the provider catalog, so a picker builds itself from one call.
`connection.start` takes an optional `domain`: without one it connects the account alone.
`provisioning.receipt(receiptId)` reads what one apply landed, for a surface holding the id rather
than the attempt.

`verification.observe(domain, options?)` takes an optional `requirements` array. Supplied
requirements win; without them the server uses the attachment's latest provisioning receipt, and a
domain with neither answers `InvalidInput`.

## Connect methods

`Transport.Method` mirrors `Connect.Method` over the wire, so a client never writes a tag literal.

| Constructor                        | Sends                                                    |
| ---------------------------------- | -------------------------------------------------------- |
| `Method.token(values)`             | A lone string, or the values the method descriptor names |
| `Method.oauth({ returnTo })`       | An OAuth start that answers with a redirect              |
| `Method.integration({ returnTo })` | A marketplace install that answers with a redirect       |

## Failures

A failure arrives as the same `DomainKit.Error` the lifecycle raised, reason intact. A reply the
transport cannot read as one is classified from its status, naming the transport's base URL as the
origin.

| Status        | Becomes                                                                  |
| ------------- | ------------------------------------------------------------------------ |
| 401           | `Unauthenticated`                                                        |
| 403           | `Forbidden`                                                              |
| 409           | `ProviderConflict`                                                       |
| 429 and 5xx   | `ProviderUnavailable`, retryable, with `retryAfterMs` from `retry-after` |
| anything else | `ProviderRejected`, carrying the status as its code                      |
