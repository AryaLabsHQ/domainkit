`Transport` is an app contract, not a provider client. Implement it on the server, authorize each
method as a product operation, and give `DomainKit.Root` a layer that calls your authenticated
endpoints.

## Constructing responses

Use the callable transport constructors when your host creates a response. Their `Schema` members
and the aggregate `ConnectionSnapshot`/`ConnectionResult` schemas are for validating serialized
wire data.

```ts
import { Transport } from "domainkit";

const plan = Transport.ProvisioningPlan({
  digest: "plan-digest",
  expiresAt: "2026-09-01T00:15:00.000Z",
  operations: [
    Transport.PlanOperation.Create({
      id: "record-1",
      record: { id: "record-1", name: "mail.example.com", type: "TXT", value: "verified" },
    }),
  ],
});

const result = Transport.ApplyResult.Applied({
  operationId: "apply-1",
  receiptId: "receipt-1",
  results: [],
});
```

This keeps `_tag` available for narrowing while avoiding handwritten tags in host implementations.

## Service methods

| Method                 | Input                    | Result               |
| ---------------------- | ------------------------ | -------------------- |
| `connection.inspect`   | `InspectInput`           | `ConnectionSnapshot` |
| `connection.connect`   | `ConnectInput`           | `ConnectionResult`   |
| `connection.attach`    | `AttachInput`            | `Connected`          |
| `connection.detach`    | `DetachInput`            | `DetachResult`       |
| `provisioning.plan`    | `ProvisioningPlanInput`  | `ProvisioningPlan`   |
| `provisioning.apply`   | `ProvisioningApplyInput` | `ApplyResult`        |
| `verification.observe` | `ObserveInput`           | `Observation`        |
| `cleanup.plan`         | `CleanupPlanInput`       | `CleanupPlan`        |
| `cleanup.apply`        | `CleanupApplyInput`      | `CleanupResult`      |

The `Interface` returns Effect values with `Failure` in the error channel. `Service` is the Effect
service accepted by the React root.

## Connection wire models

- `Provider` describes display-safe provider identity and authentication methods.
- `ProviderConnection` describes a connection tied to a credential; `ProviderTarget` describes an
  exact provider account and zone; `DomainAttachment` binds the two to one domain.
- `Connected`, `Disconnected`, and `Unsupported` form `ConnectionSnapshot`.
- `ConnectionResult` is either `Connected` or `Redirect`.
- `Disconnected.reusableConnections` lists existing provider connections and their discovered
  targets. `AttachInput` requires an explicit target and attaches without reconnecting.
- `DetachInput` identifies a `DomainAttachment` and requires `preserveDns: true`; DNS deletion is
  the independent cleanup flow. `DetachResult` retains the connection and reports the remaining
  attachment count, including zero for a final attachment.

## Plan and result wire models

- `ProvisioningPlan` contains `digest`, `expiresAt`, and `PlanOperation` values.
- `PlanOperation` is `Create`, `Noop`, or `Conflict`.
- `ApplyResult` is `Applied`, `Partial`, or `Stale` and contains per-operation results when present.
- `CleanupPlan` contains receipt-bound `Delete`, `AlreadyAbsent`, or `Blocked` operations.
- `CleanupResult` is `Cleaned`, `Partial`, or `Stale`.

The browser submits only the saved digest when applying a plan. The server loads the plan, checks the
authenticated actor, approves the requested operation, and stores the result.

## Observation wire models

`ObserveInput.sources` turns provider and public-DNS checks on or off. `Observation` returns each
source separately as `Found`, `Mismatch`, `Missing`, or `Unavailable`. The host maps that evidence
into product status and retry rules.

## Promise adapter

`AsyncInterface` mirrors all service methods with Promises. Use `fromAsync` to produce an Effect
`Interface`, or `layerFromAsync` to produce a `Layer<Transport.Service>`. `toAsync` adapts an Effect
implementation to Promises. `AsyncOptions.onError` can map other failures to `Transport.Failure`.

```ts
import { Transport } from "domainkit";

export const layer = Transport.layerFromAsync({
  connection: api.connections,
  provisioning: api.provisioning,
  verification: api.verification,
  cleanup: api.cleanup,
});
```

checklist.
